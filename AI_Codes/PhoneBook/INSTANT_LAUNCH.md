## 🔧 TROUBLESHOOTING

### "Flask not installed"
```bash
pip install Flask
```

### "Address already in use"
Use different port:
```bash
python -c "from app import app; app.run(port=8000)"
```
Then go to `http://127.0.0.1:8000`

### "Browser didn't open"
Manually go to: `http://127.0.0.1:5000`

### "Can't find templates"
Make sure you're in the right directory:
```bash
cd /home/erhan/work/learning/PythonProgramming/PythonRepo/AI_Codes/PhoneBook/
ls templates/index.html  # Should show: templates/index.html
```
