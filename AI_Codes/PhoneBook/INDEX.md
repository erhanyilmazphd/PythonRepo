## 🎓 Technical Details

### Data Structure: Doubly-Linked List
- Each contact is a node with `prev` and `next` pointers
- Allows efficient traversal in both directions
- Suitable for sequential access and sorting

### Algorithms
- **Search**: Linear search O(n)
- **Sort**: Bubble sort O(n²)
- **Add**: O(1)
- **Delete**: O(n)

### File Format
- **JSON**: Human-readable, easy to parse
- **CSV**: Excel-compatible, spreadsheet-friendly

### Dependencies
- **Python 3.6+**: Only standard library
- **tkinter**: Comes with Python
- **No external packages needed!**

## 🔧 Troubleshooting

### "Application won't start"
- Check Python version: `python --version`
- Should be 3.6 or higher
- Try: `python3 gui_app_modern.py`

### "tkinter not found"
- On Ubuntu/Debian: `sudo apt-get install python3-tk`
- On macOS: Should be pre-installed
- On Windows: Should be pre-installed

### "Lost my contacts"
- Check `phonebook.json` file exists
- Try loading from backup file

### "Can't find saved file"
- Files save in current directory
- Check same folder as the .py files
- Use "Load" dialog to find files

### "GUI looks weird"
- Resize window by dragging edges
- Should work on Windows, macOS, Linux
