  ewma_factor = 0.3           # 0.1=stable, 0.7=fast

================================================================================
                         TROUBLESHOOTING GUIDE
================================================================================

PROBLEM: "ModuleNotFoundError: No module named 'numpy'"
SOLUTION: pip install numpy matplotlib

PROBLEM: Visualization window doesn't appear
SOLUTION: Use headless mode: python run_simulator_headless.py

PROBLEM: All algorithms select same channel
SOLUTION: Increase base_interference variation or add more channels

PROBLEM: Too many channel switches
SOLUTION: Increase switch_threshold or min_dwell_time

PROBLEM: Low fairness values
SOLUTION: Increase fairness_param (closer to 1.0)

PROBLEM: Unclear algorithm behavior
SOLUTION: Read SIMULATOR_README.md → Implemented Algorithms

PROBLEM: Want to customize

================================================================================
                      PERFORMANCE CHARACTERISTICS
================================================================================

COMPUTATIONAL:
  Time per step: O(F·N) where F=channels, N=stations
  Space complexity: O(F·N) for rate matrix
  Typical (8 stations, 4 channels): 32 ops/step
  Full simulation (200 steps): ~10ms pure computation
  With visualization: ~500ms
  Headless output: ~100ms per experiment

MEMORY:
  Rate matrix: F·N floats (~256 bytes for 8×4)
  History: F·N·H where H=history_length (3,200 floats typical)
  Metrics storage: O(F·N)
  Total: <10 MB for large scenarios

SCALABILITY:
  Tested up to: 32 stations, 8 channels, 1000 steps
  Linear scaling with N and F
  Suitable for real-time embedded systems
