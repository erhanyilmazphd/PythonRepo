================================================================================
  THE 6 IMPLEMENTED ALGORITHMS
================================================================================

1. Throughput Maximizer
   Focus: Maximum aggregate rate
   Pros: Highest capacity
   Cons: May starve some users

2. Max-Min Fairness
   Focus: Protect worst-case user
   Pros: Guarantees QoS for all
   Cons: May sacrifice throughput

3. Jain's Fairness Index
   Focus: Balanced fairness metric
   Pros: Mathematically principled
   Cons: Indirect throughput focus

4. WTF (Weighted Throughput-Fairness)
   Focus: 70% throughput, 30% fairness
   Pros: Good balance
   Cons: Fixed weights

5. HPF-ACS (Hybrid Proportional Fair)
   Focus: 50% throughput, 30% fairness, 20% proportional
   Pros: Comprehensive approach
   Cons: More parameters to tune

6. Adaptive HPF-ACS
   Focus: Auto-tuning weights based on fairness
   Pros: Adapts to conditions
   Cons: More complex

All algorithms automatically compared on same network scenario.

================================================================================
  KEY METRICS EXPLAINED
================================================================================

Throughput (Mbps)
  - Sum of achievable rates across all stations
  - Higher = better capacity
  - Can hurt fairness if focused exclusively

Minimum Rate (Mbps)
  - Rate of worst-performing user
  - Higher = better fairness guarantee
  - Indicator of QoS for edge users

Fairness Index (Jain's, 0-1)
  - 1.0 = perfectly fair
  - 0.9+ = good fairness
  - <0.8 = unfair distribution

Channel Switches
  - Number of times algorithm changed operating channel
  - Lower = more stable
  - Higher = more adaptive

================================================================================
  CONFIGURATION PARAMETERS
================================================================================

You can customize:

Network:
  - n_stations (2-50 typical)
  - n_channels (1-14 typical for WiFi)
  - n_time_steps (100-1000 typical)

Wireless Conditions:
  - min_rate, max_rate (in Mbps)
  - fairness_param (0=random, 1=uniform)
  - base_interference (per channel)
  - interference variability (AWGN noise)

Algorithm Behavior:
  - switch_threshold (how much improvement needed)
  - min_dwell_time (minimum time on channel)
  - ewma_factor (rate smoothing)

See SIMULATOR_README.md for complete parameter reference.
